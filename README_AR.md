# منصة الأستاذ محمد صلاح الجبالي

مشروع بداية لموقع تعليمي عربي (RTL) باستخدام Next.js وSupabase.

## تشغيل محليًا
1. ثبّت Node.js إصدار LTS.
2. من داخل مجلد `apps/web` شغّل `npm install`.
3. انسخ `.env.example` إلى `.env.local` وأضف بيانات Supabase العامة.
4. شغّل `npm run dev`.

## النشر
ارفع محتويات هذا المشروع إلى GitHub، ثم اربط المستودع بـ Vercel واجعل Root Directory هو `apps/web`.

## تنبيه أمني
هذا نموذج أولي للواجهة. لا تضع service_role أو كلمة مرور قاعدة البيانات في متغيرات NEXT_PUBLIC أو في المتصفح. راجع سياسات RLS واختبرها قبل استخدام بيانات طلاب حقيقية أو إطلاق اشتراكات مدفوعة.
